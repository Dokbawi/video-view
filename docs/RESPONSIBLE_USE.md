# 녹음·공유 및 무보증 안내

VideoView는 내 컴퓨터에서 녹음·녹화하고 필요한 부분을 공유 파일로 만드는 무료 개인 오픈소스 프로젝트입니다. 이 문서는 안전한 이용을 위한 안내이며, 별도 동의나 추가 이용약관이 아닙니다.

## 녹음하기 전에

- 참여자에게 녹음 사실을 알리고, 적용되는 법과 상황에 따라 필요한 동의·권한을 확인하세요. 필요한 동의의 범위는 지역과 대화 상황에 따라 다를 수 있습니다.
- 본인이 참여하지 않는 비공개 대화를 권한 없이 녹음하지 마세요.
- 최근 구간 보관과 자동 기록도 녹음입니다. 마이크, 앱 소리, 화면 범위를 확인하고 필요한 대상만 선택하세요. 컴퓨터 전체 소리에는 다른 앱의 음성도 들어갈 수 있습니다.
- 공유하지 않을 대화·알림·비밀번호·계정 정보가 화면에 들어가지 않도록 주의하세요.

## 공유하기 전에

- 미리보기에서 목소리·채팅·알림·개인정보와 공개 권한을 확인하세요. 녹음할 수 있는 상황이어도 공개·전송에는 별도의 검토가 필요할 수 있습니다.
- 필요하면 구간을 자르거나 음원을 제외하세요. 편집 후에도 민감한 화면이 남으면 공유하지 마세요. 현재 앱에는 화면 일부를 가리는 모자이크 기능이 없습니다.
- 음악·게임·영상 등 녹화된 콘텐츠의 저작권과 서비스 이용 조건을 확인하세요. VideoView의 GPL 라이선스는 앱 코드에 적용되며, 녹화된 콘텐츠의 권리를 대신 허락하지 않습니다.
- 파일은 로컬에 저장되고 앱이 자동 업로드하지 않습니다. 파일 복사·끌어놓기 후 실제 첨부·전송은 사용자가 진행합니다. 설치 과정에서는 공식 배포처에서 미디어 도구를 다운로드하며, 앱의 웹 링크는 사용자가 눌렀을 때 브라우저로 엽니다.
- 문제를 제보할 때도 녹화 파일·로그·화면 이미지의 개인정보를 먼저 확인하세요.
