# VideoView 작업 화면

## v0.5 편집·공유

- 편집기는 미리보기와 오른쪽 음원 패널을 나란히 배치합니다. 재생 조작과 시간축은 아래에서 전체 폭을 사용합니다. 작은 창에서는 음원 목록만 스크롤하고 적용 버튼은 유지합니다.
- 제목 Enter로 이름 저장, 별 버튼으로 즐겨찾기. 폴더 열기·이름 변경·삭제는 파일 메뉴로 모았습니다. 오른쪽 위 ‘공유 파일 만들기’에서 현재 구간·음원·음량의 스냅샷을 가져옵니다.
- 공유 창: **대상 → 크기·형식 → 생성 → 전달**. Discord와 로컬 파일 저장을 지원합니다. 10/20/50/100MB와 직접 입력, MP4/M4A, 예상 영상 비트레이트, 저장 폴더를 표시합니다. 원본은 유지합니다.
- 생성 중 진행률과 취소, 실패 시 같은 화면에서 재시도. 파일 크기·재생 정보 검사 후에만 완료 카드를 표시합니다. 완료 카드의 끌어놓기·파일 복사는 Windows 파일 전달이며 자동 업로드가 아닙니다.
- 하단 주 동작은 고정하고 본문만 스크롤합니다. 이전 단계·다른 크기로 만들기를 지원합니다. 닫기는 진행 작업 취소와 정리를 기다립니다.
- 홈에서 현재 확보한 시간, 임시 버퍼 사용량, 저장 요청으로 보호 중인 상태를 표시합니다. 저장을 요청해도 기록을 유지합니다. 저장 완료 알림은 최종 파일 검사 뒤에 표시합니다.

벤치마킹 근거와 사용자 반응의 한계는 [UX_RESEARCH.md](UX_RESEARCH.md)에 기록했습니다.

## v0.4 추가 흐름

- 녹화 화면의 중요 순간 버튼과 변경 가능한 전역 키 `Ctrl+Shift+F6`. 현재 기록에 쌓인 표시 수, 표시 성공·실패를 즉시 알립니다. 리플레이를 저장하는 중에도 표시할 수 있습니다.
- 편집기는 녹화에서 저장한 표시를 첫 화면에 복원합니다. 시간축 표시, 시간 목록, 이전·다음 이동으로 긴 파일의 중요한 위치에 접근합니다. 저장된 편집 위치가 없으면 첫 표시를 엽니다.
- 현재 20초 구간 먼저 준비, 파형 분석은 독립 실행. 탐색 중에는 요청 위치를 표시하고 빠른 연속 탐색에서 오래된 작업을 취소합니다. 다음 구간은 종료 5초 전부터 미리 준비합니다.
- 미리보기는 최대 720p이며 원본 FPS 유지. 원본 기반 내보내기임을 화면에 표시합니다. 완전한 무중단 미리보기 전환을 보장하지 않으며 처음 보는 구간이나 플레이어 소스 전환에 짧은 대기가 있을 수 있습니다.
- 캐시는 원본 경로·크기·수정/생성 시각·트랙 구성과 음량 설정별로 분리합니다. 손상된 캐시는 재생성하고 재생 중인 파일은 자동 정리에서 제외합니다.

기술 근거: [FFmpeg 정확한 탐색](https://www.ffmpeg.org/ffmpeg.html)은 입력 `-ss`와 재인코딩 시 앞선 키프레임 구간을 버려 요청 위치를 맞춥니다. 미리보기 시작점의 어긋남을 막기 위해 짧은 구간만 재인코딩합니다. [WPF 소스 전환 구현](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/AVElementHelper.cs)은 Play에서 대기 중인 Source 변경을 확정합니다. 무음으로 먼저 열고 MediaOpened에서 일시정지·탐색한 뒤 소리를 복원해, Pause로 열었을 때 탐색이 초기화되는 문제를 방지합니다.

## v0.2 당시 설계

v0.3 추가 변경과 출처는 [UX_RESEARCH.md](UX_RESEARCH.md)를 참고하세요. 아래는 v0.2 당시의 설계 기록입니다.

사용자가 첨부한 SteelSeries Moments 편집 화면을 시각적 기준으로 삼았습니다. 원본 이미지·로고·게임 화면을 앱 자산으로 복제하지 않았습니다.

- 큰 미리보기, 바로 아래 재생 조작, 하단 시간축과 소리 믹서. 파일 목록은 접고 작업 영역을 넓힐 수 있습니다.
- 소개 문구와 세로 내비게이션을 줄여 상단 작업 탭으로 이동. 홈은 캡처 대상과 기록 버튼을 나란히, 설정은 두 열로 배치했습니다.
- 선택 구간은 선·음영·양끝 손잡이와 실제 길이로 표시합니다. 클릭 탐색, 구간 이동, 확대, 숫자 입력, 키보드 조작을 함께 제공합니다.
- 소리 변경은 적용 필요 표시와 함께 재생을 일시정지합니다. 적용 전 음량으로 계속 들려주는 혼동을 줄였습니다.
- 전역 단축키는 직접 누르는 입력 방식이며, 서로 충돌하면 이전 등록을 보존합니다.

참고한 공식 자료:

- [SteelSeries Moments](https://steelseries.com/gg/moments): 녹화에서 간편 편집·공유로 이어지는 흐름. 화면 배치는 사용자 첨부가 기준입니다.
- [Medal 장시간 녹화 편집 안내](https://support.medal.tv/support/solutions/articles/48001159728-how-to-create-clips-from-a-long-recording): 시간축 확대와 방향키 5초 탐색을 참고했습니다. 북마크·여러 클립 구성은 이번 구현 범위가 아닙니다.
- [OBS Studio 공식 개요](https://github.com/obsproject/obs-studio/wiki/OBS-Studio-Overview): 녹화 및 리플레이 제어의 단축키 분리와 음원별 조작을 참고했습니다.
- [Microsoft 화면 캡처 문서](https://learn.microsoft.com/en-us/windows/apps/develop/media-authoring-processing/screen-capture): 크기 변경 시 프레임 풀 재생성을 적용했습니다.
