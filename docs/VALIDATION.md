# 구현 검증 기록

## v0.5.1 자동 준비 EXE · 2026-10-28

- .NET 10 / Windows x64 Release 배포 빌드 성공. 앱 버전 0.5.1.0. 녹화 엔진은 v0.5.0과 동일합니다.
- 설치 흐름 **30개 검사 통과**. 공백을 포함한 경로에서 공식 ZIP 준비, 두 도구의 해시, GPL·제3자 고지, 시작 메뉴, 설치된 도구의 무음 MP4 생성·분석, 앱 렌더, 재설치의 다운로드 생략을 확인했습니다.
- 잘못된·없는 ZIP 거부, 실행 중 앱의 설치 차단, 실패한 업데이트의 기존 앱·녹화 보존, 제거 후 원본·설정 보존을 확인했습니다. 설치 폴더 안에 둔 사용자 파일도 남았습니다.
- 기존 사용자 앱을 유지하기 위해 실제 설치 코드를 별도 AppId·뮤텍스·바로가기로 컴파일했습니다. 자동 실행만 격리된 무음 렌더 인자를 사용하며 캡처는 하지 않습니다. 증거: `.artifacts/installer-tests-local.log`, `.artifacts/installer-test-8cca67de158044b6924deec9ed81cbad/results.json`.
- 공식 서버 다운로드와 SHA-256 검증 성공을 확인했습니다. 후속 다운로드의 장시간 지연도 관찰해, 진행 콜백에서 45초간 수신 증가가 없으면 중단·재시도 안내를 표시하도록 추가했습니다. 인터넷이 필요 없는 설치 파일은 아닙니다.
- 실제 Windows PowerShell 5.1에서 ZIP 파일 4개만 추출하고 해시를 확인했습니다. PowerShell 7의 모듈 경로가 상속되는 환경에서도 작동하도록 프레임워크 API를 사용합니다.
- 일반 실행에서 다음·설치·완료 버튼을 누르지 않고 공식 다운로드 → 검증 → 앱 설치 → 자동 실행까지 완료했습니다. 진행 창의 한국어 문구·진행률과 자동 실행된 앱의 무음 렌더를 확인했습니다. `.artifacts/installer-gui-progress.json`, `.artifacts/installer-gui-bcda9650b7614a28a194e377c68a135b/auto-start.log`, 인접 `app/installer-launch.png`.

- README 화면은 합성 데이터만 사용하며 개인 대화·사용자 경로를 포함하지 않습니다.

아래 `.artifacts` 경로는 개발 PC의 로컬 증거 위치입니다. 해당 녹화·로그·임시 데이터는 공개 저장소에 포함하지 않습니다.
