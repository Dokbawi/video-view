# 사용 가이드

## 사용

1. **홈:** 음성만 또는 화면+음성 선택. 모니터·창은 직접 선택합니다.
2. 마이크와 녹음할 앱을 체크합니다. 앱을 찾을 수 없으면 해당 앱에서 소리를 재생하고 **새로고침**을 누르세요. 컴퓨터 전체 소리는 앱별 선택과 동시에 사용되지 않습니다.
3. **입력 테스트**, **미리보기**로 확인. 테스트 중인 입력은 파일로 저장하지 않습니다.
4. **녹화 시작**은 연속 기록. **최근 구간 보관 켜기**는 최대 5분 순환 보관. 둘 다 동시에 켤 수 있습니다.
5. **방금 순간 저장** 또는 기본 단축키 **Ctrl+Shift+F8**로 직전 구간 저장. 시작 전 장면은 복구할 수 없으며, 아직 충분히 쌓이지 않았다면 확보된 길이만 저장합니다.
6. **보관함:** 파일 선택 → 시간축 손잡이로 구간 지정 → 오른쪽에서 음원별 소리 조절 → **공유 파일 만들기**. 목록은 접어 화면을 넓게 사용할 수 있습니다.
7. 공유 창에서 대상·용량·형식을 고르고 파일을 만듭니다. 영상은 H.264/AAC MP4, 음성은 AAC M4A. 목표 용량은 decimal MB입니다. 완성 카드에서 파일을 끌거나 **파일 복사** 후 디스코드에 직접 붙여넣으세요. ‘다른 크기로 만들기’는 기존 파일을 보존합니다. 생성 중 취소·닫기는 임시 파일을 정리합니다.

### 단축키

| 동작 | 기본 전역 단축키 |
| --- | --- |
| 녹화 시작 / 종료 및 저장 | Ctrl+Shift+F9 |
| 최근 구간 보관 켜기 / 끄기 | Ctrl+Shift+F7 |
| 방금 순간을 파일로 저장 | Ctrl+Shift+F8 |
| 녹화 중 중요 순간 표시 | Ctrl+Shift+F6 |

**설정 → 단축키**에서 입력칸을 클릭하고 원하는 키 조합을 누른 뒤 **설정 저장**을 누르세요. 게임 등 다른 프로그램에서도 동작합니다. 보관 켜기는 과거 저장을 준비하는 기능이며, 실제 클립 파일은 ‘방금 순간 저장’으로 만듭니다. 중복 키 및 다른 앱과의 충돌은 표시하고, 변경 실패 시 기존 등록을 유지합니다.

편집기: `Space` 재생/일시정지, `I` 시작점, `O` 끝점, `←/→` 5초 이동, `Shift+←/→` 원본 FPS 기준 한 프레임 이동, `Home/End` 선택 구간의 양 끝, `Ctrl+Z` 구간 변경 되돌리기. 텍스트 입력 중에는 편집 단축키를 가로채지 않습니다.

시간축 클릭으로 탐색, 휠로 확대/축소, **Shift+드래그**로 선택 길이를 유지하며 이동합니다. 숫자로 초 단위를 직접 지정할 수도 있습니다. 소리 변경 후 **소리 적용** 또는 **재생**을 누르면 미리듣기에 반영됩니다. 파형은 원본 음성 기준입니다.

**중요 순간:** 녹화 또는 최근 구간 보관 중 `Ctrl+Shift+F6`을 누르거나 홈의 **중요 순간 표시**를 누르세요. 연속 녹화는 원본에, 최근 구간은 나중에 저장하는 클립 안에 포함된 지점만 보존합니다. 보관만 켠 상태에서 표시 자체가 영상 파일을 저장하는 것은 아닙니다. 편집기 시간축의 다이아몬드, 지점 목록, 이전·다음 버튼으로 이동합니다. 편집기 `M`은 현재 위치의 표시 추가/제거입니다. 표시된 원본을 처음 열면 첫 중요 지점부터 보여주고, 이후에는 마지막 편집 위치를 복원합니다. 파일당 최대 500개입니다.

**빠른 미리보기:** 현재 위치가 포함된 20초 구간부터 준비하고, 재생 중 다음 구간을 미리 준비합니다. 파형은 뒤에서 분석하며 한 번 만든 구간과 파형은 재실행 후에도 재사용합니다. 미리보기만 최대 720p, 원본 FPS를 유지하며 내보내기는 원본으로 만듭니다. 음량·포함 음원 또는 원본이 변경되면 해당 캐시를 다시 만듭니다. 새 구간 최초 준비와 구간 경계의 플레이어 전환에는 짧은 대기가 있을 수 있습니다.

미리보기 캐시는 앱 설정 폴더의 `PreviewCache-v1`에 저장되며 512MiB 기준으로 오래된 것부터 정리합니다. 재생·미리 준비 중인 구간은 보호하므로 일시적으로 상한을 넘을 수 있습니다. 녹화 버퍼와 별도이며 원본·저장한 클립은 자동 삭제하지 않습니다.

### 녹음·공유 안내

녹음 전에는 참여자에게 알리고 필요한 동의·권한을 확인하세요. 최근 구간 보관·자동 기록에도 같은 주의가 필요합니다. 공유 전에는 목소리·채팅·알림·개인정보와 공개 권한을 확인하고, 중요한 원본은 별도로 백업하세요.

**녹화 → 이용 안내** 또는 **설정 → 이용 안내 · 라이선스**에 자세한 안내와 오프라인 GPL 원문이 있습니다. 반복 동의창이나 확인 체크박스는 없습니다. [녹음·공유 및 무보증 안내](RESPONSIBLE_USE.md)를 참고하세요.

### 저장 및 복구

- 원본: Windows ‘동영상’ 아래 `VideoView/yyyy-MM-dd`. 설정에서 변경 가능.
- 영상 원본 MKV, 음성 원본 MKA. 각 음원은 별도 트랙으로 저장됩니다. 보관함 메타데이터는 인접 `.recording.json` 파일.
- 공유 파일은 별도 생성. 원본을 덮어쓰지 않습니다. 이름 변경은 보관함 제목만 변경합니다.
- 임시 버퍼 기본 상한 2GiB. 2초 인코딩 조각 단위 정리이며 쓰는 중인 마지막 조각에 한해 최대 64MiB 여유를 둡니다. 저장 요청을 받은 조각은 원본 폴더의 `.sessions`에 보존합니다. 같은 볼륨에서는 하드 링크로 데이터 중복 복사를 피하고, 지원되지 않으면 복사합니다. 버퍼에서 오래된 링크를 제거해도 보존한 조각은 유지됩니다. 용량이 부족하면 보관 시간이 짧아질 수 있으며, 저장 중 보호한 조각은 일시적으로 정리를 지연시킬 수 있습니다.
- 저장 성공은 파일 생성·검사·메타데이터 저장이 끝난 후 표시합니다. 실패한 조각은 **설정 → 중단된 연속 녹화 복구**에서 재시도합니다. 강제 종료 시 마지막 미완성 조각은 손실될 수 있습니다.
- 시작 프로그램 등록·실행 시 자동 기록은 기본 꺼짐. 자동 기록은 이전 선택을 확인할 수 있을 때만 시작합니다. 대상 창/앱이 재실행돼 식별자가 바뀌면 다시 선택해야 합니다.
- 기록 중 창 닫기/최소화는 트레이로 이동합니다. 완전 종료는 트레이 메뉴. 종료 시 녹화 정리가 끝날 때까지 기다립니다.
