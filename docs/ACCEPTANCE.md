# 실사용 인수 검증

자동 테스트는 합성 입력으로 파일 정확성·트랙 분리·복구를 검사합니다. 아래 항목은 실제 PC와 대상 앱에서 추가 확인합니다. 개인 대화 대신 참여자가 알고 있는 테스트 대화를 사용하세요.

### v0.5 추가 확인

- 공유 창: 대상 선택, 프리셋/직접 용량, MP4/M4A, 미포함 음원, 저장 폴더 변경, 실제 바이트 검사. 작은 창에서도 주 동작에 접근 가능해야 합니다.
- 생성 중 취소·창 닫기·앱 종료: 성공 표시 없이 작업과 임시 파일을 정리하고 원본을 유지해야 합니다. 생성 실패 후 같은 창에서 재시도할 수 있어야 합니다.
- 완료 파일: 복사/끌어놓기 전에 존재·크기를 확인하고, 다른 크기를 만들어도 기존 파일을 유지해야 합니다. 실제 Discord 첨부·재생은 별도로 확인합니다.
- 버퍼: 동일 볼륨의 하드 링크와 다른 볼륨의 복사를 각각 확인합니다. 저장 도중 보존 실패·연속 녹화 종료가 겹쳐도 미완성 원본을 완료로 표시하거나 복구 조각을 지우면 안 됩니다.
- 성능: 공유 인코딩·최근 구간 저장 중에도 게임 FPS/1% low와 전체 프로세스의 CPU/GPU를 측정합니다. CSV 읽기량·관리 루프 시간만으로 전체 성능을 판정하지 않습니다.

측정 보고서에 OS 빌드, CPU/GPU, 드라이버, 소스 해상도·FPS, 선택 인코더, 저장 장치, 테스트 시간을 포함합니다. 자동 저장 성공 알림과 실제 파일 존재·재생을 함께 확인합니다.
